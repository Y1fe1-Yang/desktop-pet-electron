# 桌面宠物 Electron 应用

真正的桌面宠物 - 漂浮在你的桌面上！

## ✨ 特性

- 🖥️ **真正的桌面应用** - 不需要浏览器，独立运行
- 🪟 **透明窗口** - 无边框透明窗口，宠物直接显示在桌面
- 🎯 **始终置顶** - 在所有窗口上方显示
- 🖱️ **可拖拽** - 随意移动宠物位置
- 🎨 **多种动画** - idle、walk、jump、happy、sleep等
- ⚙️ **系统托盘** - 最小化到系统托盘，右键菜单
- 🔄 **自动漫游** - 宠物会自己在桌面上走动
- 💾 **设置保存** - 位置、大小等设置自动保存

## 🚀 快速开始

### Windows 用户

#### 方法1: 下载预编译版本（最简单）
暂无预编译版本，请使用方法2

#### 方法2: 从源码运行

1. **安装 Node.js**
   - 下载: https://nodejs.org/
   - 安装 LTS 版本（推荐 v20+）

2. **下载项目**
   ```bash
   # 下载并解压 ZIP，或者使用 git
   git clone https://github.com/Y1fe1-Yang/desktop-pet-electron.git
   cd desktop-pet-electron
   ```

3. **安装依赖**
   ```bash
   npm install
   ```

4. **运行**
   ```bash
   npm start
   ```

5. **打包成可执行文件（可选）**
   ```bash
   npm run build
   ```
   打包后的文件在 `dist/` 文件夹中

## 🎮 使用方法

### 启动后
- 宠物会出现在屏幕中央
- 它会自动开始漫游（随机走动）

### 交互方式
- **拖拽** - 鼠标按住宠物拖动
- **双击** - 触发特殊动画
- **系统托盘图标** - 右键查看菜单

### 系统托盘菜单
- **设置** - 打开设置窗口
- **显示/隐藏** - 切换宠物可见性
- **退出** - 关闭应用

---

## ⚙️ 配置选项

在设置窗口中可以调整：
- **宠物大小** - 调整显示尺寸
- **移动速度** - 漫游速度
- **开机启动** - 是否随系统启动
- **位置** - 重置到默认位置

## 🎨 自定义宠物

要替换成自己的宠物图片：

1. 准备精灵图（PNG格式，透明背景）
2. 每个动画一个文件，命名为 `动画名.png`
3. 放到 `sprites/` 文件夹
4. 重启应用

### 精灵图格式
- 横向排列的帧序列
- 每帧尺寸：64x64 像素
- 透明背景（RGBA）

## 🐛 常见问题

### Q: Windows Defender 报警？
**A**: 这是因为应用未签名。右键 → "更多信息" → "仍要运行"

### Q: 宠物不显示？
**A**:
1. 检查系统托盘图标
2. 右键 → "显示"
3. 重启应用

### Q: 如何卸载？
**A**:
1. 系统托盘右键 → "退出"
2. 删除应用文件夹
3. 删除配置文件（在 `%APPDATA%/desktop-pet/`）

### Q: 宠物太大/太小？
**A**: 系统托盘右键 → "设置" → 调整大小滑块

### Q: 如何禁用开机启动？
**A**: 设置窗口 → 关闭"开机启动"选项
